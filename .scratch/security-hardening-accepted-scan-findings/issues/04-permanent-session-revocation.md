# 04 — 让账号停用永久撤销旧会话

**What to build:** 让管理员停用账户成为不可逆的会话撤销事件，使重新启用账户只能通过新登录恢复访问，不能复活停用前的长期 Cookie。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 停用账户在一个事务中推进撤销版本并删除或失效全部现有受信任设备。
- [ ] 停用后再启用，旧 Cookie 始终返回 401。
- [ ] 重新启用后的新登录可以创建新会话并正常访问。
- [ ] 180 天会话期限和正常离线优先行为保持不变。

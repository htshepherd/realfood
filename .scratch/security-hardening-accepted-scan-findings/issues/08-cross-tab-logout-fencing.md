# 08 — 同步跨标签页退出并阻止陈旧写入

**What to build:** 让同一浏览器中的所有 realfood 标签页共享退出事件，并用账户/退出代际阻止退出前启动的异步操作在退出后重新写回私有状态。

**Blocked by:** 07 — 让离线收藏队列绑定账户.

**Status:** ready-for-agent

- [ ] 任一标签页退出后，所有同源标签页立即返回登录界面并清除内存详情、账户、知识版本和收藏。
- [ ] 所有标签页的 IndexedDB、Pagefind/私有缓存和待同步操作被清除。
- [ ] 退出或切换账户后才完成的收藏操作不能重建队列或界面状态。
- [ ] iPhone WebKit 多标签页、账户切换和离线受信任设备行为通过验收。

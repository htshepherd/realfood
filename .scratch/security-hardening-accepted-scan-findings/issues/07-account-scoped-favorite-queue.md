# 07 — 让离线收藏队列绑定账户

**What to build:** 让每个离线收藏操作保留创建它的账户身份，只能在服务端当前账户与该身份一致时重放，防止账号切换污染其他家庭成员的收藏。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 待同步收藏操作包含账户身份并存入账户级队列。
- [ ] 重放前先取得在线账户并核对身份，不匹配操作不会提交到服务端。
- [ ] 账户 A 的离线操作不会在登录账户 B 后改变 B 的收藏。
- [ ] 正常离线收藏、恢复联网同步和跨设备收藏继续工作。

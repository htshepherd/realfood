# 05 — 隔离并保护候选静态资源构建

**What to build:** 让候选知识版本只能读取授权根目录中的安全普通文件，把优化图片写入候选空间，并确保危险文件名和终端显示不能绕过人工发布审查。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 候选构建拒绝符号链接、特殊文件、越出根目录的规范路径及平台可识别的多链接文件。
- [ ] 内容和资源文件名拒绝控制字符、转义字符、方向控制字符、路径分隔和歧义点段。
- [ ] 发布报告对名称执行安全转义，终端控制序列无法重写审查内容。
- [ ] 候选构建和活动版本校验均不修改活动资源树。
- [ ] 优化 PNG/WebP 只产生在候选版本隔离目录，候选清单保持完整。

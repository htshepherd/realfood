# 06 — 按知识版本清单发布和提供栅格资源

**What to build:** 把人工确认的资源清单贯穿上传与鉴权资源读取，只发布不可变、版本化、校验一致的 PNG/WebP，让额外文件、漂移字节和 SVG 无法进入应用同源。

**Blocked by:** 05 — 隔离并保护候选静态资源构建.

**Status:** ready-for-agent

- [ ] 上传只接受确认清单列出的普通文件，并校验字节长度、媒体类型和摘要。
- [ ] 对象使用知识版本前缀且不可用不同字节覆盖同一版本键。
- [ ] 鉴权资源接口只解析活动知识版本清单中的 PNG/WebP。
- [ ] SVG、额外文件、摘要不匹配和未列出资源均不能返回可执行内容。
- [ ] 正常图片继续通过私有 MinIO 和本地回退按需加载。

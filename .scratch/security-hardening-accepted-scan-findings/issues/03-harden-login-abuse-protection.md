# 03 — 加固登录滥用防护

**What to build:** 让登录失败按有效来源和目标账户分别受限，避免一个成功账户清除针对另一个账户的保护，并让未知、停用和错误密码账户具有一致的公开行为和密码验证成本。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 登录账户 A 不会清除针对账户 B 的失败历史或锁定状态。
- [ ] 来源限制有可信代理地址、过期清理和容量上限，目标账户保护可跨应用重启保持。
- [ ] 未知、停用和错误密码返回相同状态、响应与相近验证路径，不产生明显 scrypt/no-scrypt 差异。
- [ ] 密码哈希并发受控，饱和时返回统一重试响应。
- [ ] 不新增密码复杂度策略，不记录搜索或浏览数据。

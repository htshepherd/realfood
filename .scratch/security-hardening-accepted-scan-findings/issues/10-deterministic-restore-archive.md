# 10 — 固定并验证恢复归档

**What to build:** 让恢复流程只读取快照根目录中确定、有效的数据库归档，不让 MinIO 资产树中的同名文件参与选择，并在破坏性操作前拒绝异常快照。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 备份布局为数据库归档和 MinIO 内容定义互不混淆的固定位置。
- [ ] 恢复只接受确切数据库归档路径，不使用递归首个匹配。
- [ ] 缺失、歧义或结构无效归档在数据库清理前失败。
- [ ] 快照选择和固定人工确认继续作为破坏性恢复前置条件。
- [ ] 含资产树诱饵归档的隔离恢复测试选择真实归档。
